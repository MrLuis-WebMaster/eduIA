# Definition of Done

Una capacidad está lista solo si:
- [ ] Tiene historia de usuario, alcance y criterios de aceptación.
- [ ] Incluye validación servidor, autorización por workspace/rol y tests positivos/negativos.
- [ ] Registra eventos relevantes, errores y acciones sensibles.
- [ ] Es responsive, accesible por teclado, tolera errores y estados vacíos.
- [ ] Tiene tests unitarios y E2E razonables; CI verde.
- [ ] Actualiza documentación y contratos REST, si aplica.
- [ ] Integraciones externas probadas con tokens de desarrollo y revocación.
- [ ] No filtra secretos, datos de alumnos ni grabaciones no autorizadas.

No confundir "interfaz demo" con una función productiva.
