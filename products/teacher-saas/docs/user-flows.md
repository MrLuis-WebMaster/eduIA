# Flujos principales

## 1. Inicio como profesor
Registro -> crear workspace SOLO -> nombre/logo/colores/slug -> definir zona horaria -> elegir materias -> añadir servicios -> fijar disponibilidad -> publicar página.

## 2. Academia
Crear ACADEMY -> invitar docentes -> definir roles -> asignar materias/cursos -> sedes/aulas -> disponibilidad por docente -> invitar alumnos -> configurar branding.

## 3. Crear sesión
Seleccionar curso o asesoría -> docente -> modalidad ONLINE/ONSITE/HYBRID -> fecha y zona horaria -> cupos -> conexión Meet/Zoom/manual o ubicación -> materiales -> confirmar -> guardar -> notificar.

## 4. Clase Viva
Sesión completada -> observaciones docente o audio -> borrador de IA con procedencia -> revisión/edición -> publicar práctica -> alumno responde -> evaluación -> recomendación -> actualización de Pasaporte.

## 5. Profe SOS
Alumno pregunta desde el curso -> validación del alcance y permisos -> asistente da pistas -> si no resuelve, derivar al docente o sugerir reserva. Conversación y telemetría minimizadas.

## 6. Materiales
Seleccionar fuente Drive/archivo/enlace -> asociar al workspace y al tema -> permisos de acceso -> mostrar en Aula Digital -> revocación o eliminación.
